# Stash

Petite appli web installable pour suivre un budget mensuel : prévu / réel par catégorie, charges fixes à cocher, solde et épargne du mois.

Les données restent sur l'appareil (stockage local du navigateur). Aucune donnée personnelle n'est dans ce dépôt.

Sauvegarde en ligne (facultative) : le script `sauvegarde-google/Code.gs`, publié depuis le compte Google de l'utilisateur, range une copie dans son Google Drive (dossier « Stash – sauvegardes », une copie par jour gardée 30 jours). Stash n'envoie jamais une appli vide.
